國小排課系統 - 規格說明與操作手冊

系統簡介與核心特色

本系統專為國小手動排課調配情境打造，提供最直覺流暢的操作體驗與四大硬性衝突即時偵測：

點選連點排課 點選左側課程卡片高亮後，直接在右側網格連點，快速排定多節課。
硬性防呆偵測 班級、教師、專科教室衝堂與教師不排課時段即時警示阻擋。
單雙週與分組 支援單週 (ODD)、雙週 (EVEN) 錯開排課，以及母語/社團分組教學排課。
右鍵浮動課表 任一課程按右鍵即可彈出教師/班級即時浮動課表，對照調配不切頁。

排課標準流程

  1. 選擇班級：由上方班級選單切換至欲排課班級，或使用「下一班」按鈕循序推進。
  2. 選取排課週別：在待排池上方選擇「每週」、「單週」、「雙週」或「分組」。
  3. 選取科目與連點：點擊左側待排卡片（青色高亮），點擊右側課表格子立即排入。
  4. 浮動預覽對照：若需確認該任課教師課表，在卡片上按「滑鼠右鍵」點選「前往課表」即可浮動對照。
  5. 匯出與備份：排課完成後，至「系統設定」匯出備份 JSON、列印 PDF 課表或匯出調代課 TSV。

作息時段與全時段排課

  • 時段結構：每日共 8 節課（上午第 1~5 節、中午午休、下午第 6~8 節）。
  • 全時段開放：無任何年級下午放學遮罩，週一至週五第 1 至 8 節皆為可排課狀態。

4 大硬性衝突偵測規則

1. 班級衝突 同一班級在相同時段只能排定一堂課。（分組課程 `GROUP` 除外，允許同班同節多師同排）
2. 教師衝突 同一位教師在相同時段只能在一處授課，不可跨班衝堂。
3. 專科教室衝突 同一間專科教室（例如電腦教室、英語教室）在相同時段只能容納一門課程。
4. 教師不排課時段 避開教師屬性中設定的不排課時段（如兼任行政或共同研習時間）。

排課週別機制說明

  • 每週 (EVERY)：全學期每週上課，佔用該時段全部週次。
  • 單週 (ODD)：僅單數週上課，可與雙週課程排在同一個時段共享課堂。
  • 雙週 (EVEN)：僅雙數週上課，可與單週課程排在同一個時段共享課堂。
  • 分組 (GROUP)：同班級可同節排多門課，課表內會以左右並列呈現。

彈出式可拖動浮動課表

排課時不再需要在班級與教師頁籤間頻繁來回切換：

班級課表排課
在左側「待排課程卡片」或右側「已排課程」上點擊滑鼠右鍵 ➔ 點選「前往課表」，右側將即時彈出該任課教師的浮動課表！
教師個人課表
在左側「授課學科清單」或「已排課程」上點擊滑鼠右鍵 ➔ 點選「前往課表」，右側將即時彈出該班級的浮動課表！

浮動視窗操作要點

  • 自由拖曳：滑鼠按住浮動視窗頂部標題列即可拖動至螢幕任意位置。
  • 最小化 / 展開：點擊標題列的「一」按鈕可折疊縮小視窗，不遮擋主畫面。
  • 排課即時連動：在主畫面排課或取消排課時，浮動課表會自動同步更新，無須手動重整！

下一班快速切換

班級課表右上角設有「下一班 」按鈕，可直接推進到下一班繼續排課。

完整系統備份與還原 (JSON)

  • 匯出系統備份：點擊「匯出系統備份 (JSON)」可下載目前所有班級、教師、教室、課程與排課資料。
  • 匯入系統備份：點擊「匯入系統備份 (JSON)」彈出專屬視窗，可直接拖曳檔案上傳或貼上 JSON 代碼，並具備即時統計解析。

CSV 批次資料匯入三部曲

1. 教師與不可排課 教師姓名, 週一, 週二, 週三, 週四, 週五
不可排課節次以分號隔開（如：1;2）。
2. 專科教室 教室名稱, 類型
類型如：自然/音樂/美勞/體育/電腦/圖書館。
3. 班級科目與任課 班級代號(或名稱), 科目, 節數, 教師, 教室
教室可留空，未填將自動對應班級教室。

* 匯入功能內建 Big5 / ANSI / UTF-8 編碼自動判斷，避免 CSV 匯入亂碼。

PDF 課表一鍵匯出 (A4 直向)

  • 全體班級與專科教室 PDF：自動分頁產生各班級與各專科教室標準課表。
  • 全體教師個人課表 PDF：自動分頁產生全體教師個人週課表與不排課時段標記。

調代課系統格式匯出 (TSV 純文字)

  • 調代課教師課表 (TSV)：橫向展開教師週一至週五第 1～8 節授課科目與班級。
  • 調代課課程資料庫 (TSV)：匯出所有排課記錄（班級、星期、節次、課程名稱、教師名稱），自動標註 (單) 與 (雙)。

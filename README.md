# 國小一般排課系統 MVP 規格說明書

本系統是專為**國小一般排課情境**量身打造的高效排課系統 MVP。系統不分年級，全時段開放排課，實作了高效率的「點選連點排課 (Click-to-Place)」、「單雙週與分組排課支援」、「右鍵彈出式浮動課表預覽」、「教師/教室/班級硬性衝突偵測」、「自動智慧切換教室」以及「完整備份與調代課系統匯出」等功能。

有自動排課需求，請使用 [FET](https://lalescu.ro/liviu/fet/)。

*   **快速入門**：關於詳細的安裝與啟動步驟（從安裝 Python 與 `uv` 開始），請參閱 [安裝與啟動指引 (INSTALL.md)](./INSTALL.md)。
*   **線上/本地操作**：支援 FastAPI 後端與純前端 IndexedDB 本地儲存模式。

## 📅 1. 時段結構與排課模式

*   **作息表**：每天共 9 行。
    *   **上午課程**：第 1、2、3、4、5 節。
    *   **中午時段**：午休時段（橫跨週一至週五，僅顯示「午休」字樣，無時間區段限制）。
    *   **下午課程**：第 6、7、8 節。
*   **全時段開放**：完全不分年級，無放學佔位與遮罩限制。週一至週五第 1 至 8 節（包含週三下午）皆為正常可排課狀態。
*   **排課週別與模式**：
    *   **每週 (EVERY)**：每週固定上課。
    *   **單週 (ODD)**：僅在單數週上課，可與同節次的雙週課程共用時段。
    *   **雙週 (EVEN)**：僅在雙數週上課，可與同節次的單週課程共用時段。
    *   **分組 (GROUP)**：分組教學模式（例如母語分組、社團分組），系統會**放寬班級衝突限制**，允許同一個班級在同一時段排入多門不同教師/專科教室之課程，並在課表內左右並列呈現。

## 🏫 2. 智慧教室與自動切換機制

1.  **普通教室整併**：
    *   系統中所有普通教室均已整併為單一的「**班級教室**」(類型為 `普通`)，並關聯至班級的 `default_classroom_id`。
    *   在科任專科教室課表檢視選單中，系統會自動**排除所有「普通」類型的教室**，僅保留專科教室（例如電腦教室、英語教室、自然教室、音樂教室、操場等）。
2.  **智慧教室自動切換 (autoSwitchClassroomForCourse)**：
    *   當管理者點選或拖曳課程卡片時，系統會自動將「安排授課教室」選單切換至該科目設定的教室類型：
        *   點選「資訊/電腦」➔ 自動切換為「**電腦教室**」。
        *   點選「體育」➔ 自動切換為「**操場**」。
        *   點選「英語/英文」➔ 自動切換為「**英語專用教室**」。
        *   其他未指定或普通科目 ➔ 自動智慧切換為該班級的「**班級教室**」。
    *   排課時若手動切換特定教室，系統會維持目前選取，方便連點排入相同專科教室。
    *   **授課教室放寬限制**：排課時選擇的教室**不需要**與科目設定中指定的預設教室類型一致即可成功排課，提供更彈性的手動調配空間。

## ⚙️ 3. 核心衝突偵測引擎 (scheduler.py)

在排定（`POST`）或調整（`PUT`）課程時，系統會即時驗證以下 **4 大硬性衝突限制**，若違反則會阻擋並回傳衝突提示：

1.  **班級衝突**：同一個班級在相同時段 `(weekday, period)` 原則上只能排定一節課（**分組課程 `GROUP` 除外**）。
2.  **教師衝突**：同一個教師在相同時間段只能在一處授課（不可重疊）。
3.  **教室衝突**：同一個專科教室在相同時間段只能容納一門課程（排除獨立的普通「班級教室」以避免誤判）。
4.  **教師不排課時段**：避開教師設定之不排課時段（儲存於教師屬性中，例如 `["1-1", "3-5"]` 代表週一第 1 節與週三第 5 節不可排課）。

*(註：單週與雙週課程因週次錯開，不判定為衝突；每週課程與單/雙週重疊則視為衝突。)*

## 🖱️ 4. 前端智慧交互與操作指南

1.  **點選連點排課 (Click-to-Place)**：
    *   點選左側待排池中的課程卡片，卡片呈現青色高亮選取狀態。
    *   直接在右側週曆網格中連續點擊多個空格，即可連續排入多節課，無需重複選取。
2.  **待排課程同科目高亮**：
    *   選取左側待排課程時，右側課表中屬於該科目的已排課程卡片會同步醒目提示，便於掌握已排時段分佈。
3.  **「下一班」快速切換**：
    *   班級課表右上角提供「**下一班**」快速切換按鈕，可循序切換至下一個班級繼續排課。
4.  **右鍵彈出式浮動課表 (Floating Draggable Schedule Window)**：
    *   **班級排課介面**：在左側待排課程或已排課程卡片上按**滑鼠右鍵** ➔ 點選「**前往課表**」，即可彈出該任課教師的浮動即時課表。
    *   **教師排課介面**：在待排課程或已排課程卡片上按**滑鼠右鍵** ➔ 點選「**前往課表**」，即可彈出該班級的浮動即時課表。
    *   浮動視窗支援**滑鼠拖曳移動位置**、**最小化/展開折疊**，且會隨排課動作**即時同步更新**。
5.  **取消排課事件防吞噬**：
    *   已排課程卡片上的「x」取消排課按鈕採用 `mousedown` 事件監聽，避免 HTML5 拖曳機制吞噬點擊事件。

## 📂 5. 系統資料管理與匯入/匯出

1.  **完整系統資料匯入/匯出 (JSON)**：
    *   **匯出系統備份**：一鍵將班級、教師、教室、課程與排課資料完整打包為 `.json` 備份檔。
    *   **匯入系統備份**：提供自訂彈窗 Modal，支援「**檔案上傳/拖放**」與「**直接貼上 JSON 內容**」，並具備解析統計預覽與覆蓋防呆提示。
2.  **CSV 批次資料匯入（三部曲）**：
    *   **1. 匯入教師與不可排課**：格式 `教師姓名, 週一, 週二, 週三, 週四, 週五`（空堂以分號隔開，若教師不存在會自動建立）。
    *   **2. 匯入專科教室**：格式 `教室名稱, 類型(普通/自然/音樂/美勞/體育/圖書館)`。
    *   **3. 匯入班級科目**：格式 `班級代號(名稱), 科目, 節數, 教師, 教室(可空白)`。
    *   *支援 Big5 / ANSI / UTF-8 多重編碼自動偵測與檔首 BOM 防亂碼處理。*
3.  **課表匯出與列印 (CSV / PDF)**：
    *   **CSV 匯出**：匯出全部班級課表 CSV、匯出全部教師課表 CSV。
    *   **PDF 一鍵匯出**：一鍵產生全體班級與專科教室 PDF、全體教師個人課表 PDF（標準 A4 直向排版，支援瀏覽器預覽與列印）。
4.  **調代課系統相容資料匯出 (TSV 純文字)**：
    *   **調代課教師課表 (TSV)**：以教師為單位，橫向展開週一至週五第 1～8 節之授課科目與班級。
    *   **調代課課程資料庫 (TSV)**：完整匯出排課紀錄，欄位包含 `班級, 星期, 節次, 課程名稱, 教師名稱`，支援單雙週標記 `(單)` / `(雙)`。
5.  **班級與節次設定檔即時編輯 (`config.json`)**：
    *   在系統設定中提供設定檔線上編輯器，可直接修改並儲存套用。
6.  **清空系統資料庫**：
    *   提供一鍵清空所有課表與排課資料功能，並具備二次確認安全防呆。
